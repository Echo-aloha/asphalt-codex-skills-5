# Burger 参数标定路线

> DSR/BBR 或连续体 Burger 常数不能唯一、直接地改名为 DEM 接触参数。
> 应固定单位、几何与分辨率，以实际 PFC RVE/试件的宏观响应为目标反演。

## 1. 推荐默认顺序（先简单后复杂，可迭代）

```
Step 1  固定几何、分辨率、接触对和宏观弹性目标
Step 2  标定非 Burger 接触及界面强度/摩擦参数
Step 3  对 Burger 接触反演 (k_m, c_m, k_k, c_k)
Step 4  若使用混合接触，标定模型占比/选择规则并审计随机拓扑
Step 5  联合复核弹性、强度与时间相关响应
```

这是一条便于获得可识别初值的默认路线，不是不可回退的硬门槛。若灵敏度、
参数相关性或试验设计表明顺序解耦不足，可采用交替迭代或有界联合反演；每次
联合更新后都要重跑独立验证，并报告参数相关性、非唯一性和所用约束。

理由：法向和切向 Burger 共含 8 个刚度/黏壶参数，且混合料宏观响应还受接触网络、摩擦/界面和边界条件影响。Burger 模型本身不含通用的黏聚力 `c` 参数，不能把宏观 `c、φ` 直接写成 Burger 属性；应先限定其他接触对和界面假设，再用多条响应曲线反演并联合复核。

## 2. 数据源与拟合方法

| 数据源 | 仪器 | 输出 | 反演目标 |
| --- | --- | --- | --- |
| 结合料动态剪切流变 | DSR | G*（复数模量）、δ（相位角），不同温度/频率 | 结合料级主曲线先验/约束；不能直接作为砂浆接触拟合目标 |
| 结合料弯曲梁流变 | BBR | 蠕变劲度 S(t)、m 值 | 结合料级低温先验/约束；不能直接作为砂浆接触拟合目标 |
| 结合料多重应力蠕变恢复 | MSCR | 不同应力下恢复与不可恢复蠕变响应 | 结合料级高温非线性/永久变形约束；不能直接改名为黏壶参数 |
| 结合料线性振幅扫描 | LAS | 幅值扫描和疲劳损伤表征 | 结合料级损伤/疲劳约束；Burger 本构本身不自动包含裂纹演化 |
| 同一砂浆材料的项目流变试验 | DSR/BBR 或其他经声明协议 | 砂浆尺度的模量、相位或蠕变曲线 | 砂浆 RVE 的候选宏观拟合目标；仍须反演为接触参数 |
| 单轴蠕变 | 万能试验机 | 蠕变曲线（60℃） | 直接拟合 Burger 蠕变 |
| 动态模量 | | \|E*\| 主曲线 | 频率域黏弹性 |

对采用 JTG 3410-2025 的项目，分别记录 BBR T 0627、DSR T 0628、MSCR
T 0647-2025、LAS T 0648-2025，以及混合料层面的动态模量/重复压缩/车辙
方法。试验编号只确定数据生成协议，不提供从宏观量到接触参数的闭式换算。

### 拟合方法

- **最小二乘**：把 Burger 模型的蠕变/动态响应表达式对试验曲线做非线性最小二乘拟合。
- **全局或多起点优化**：可用于初值敏感的多参数拟合；必须报告算法、边界、随机种子和收敛检查。

宏观黏弹性 → 微观 Burger 参数的映射：JTG T 0627/T 0628 的默认试验对象是沥青结合料。只有实际对同一砂浆材料执行并完整声明试验协议时，DSR/BBR 类曲线才可作为砂浆 RVE 的宏观拟合目标；即使如此，也不能直接改名为 PFC 接触参数。接触刚度和黏壶参数的量纲、数值尺度取决于 PFC2D/PFC3D、单位制、颗粒尺度、配位和接触几何，必须通过固定离散化后的探针/RVE/试件响应反演。

弹性梁或等效接触面积推导可以生成带单位的初值，但其截面积、球心距、串联
接触数和法/切向换算必须与实际离散化一致。先对宏观砂浆蠕变曲线做四参数拟合，
再把拟合量闭式换成接触量，仍不等于完成 DEM 标定；必须用同一砂浆 RVE 复现
加载与回复，并用留出温度/时长确认。仅报告很高的加载段 `R²` 不能证明参数可
识别、回复正确或车辙路径有效。

若砂浆相关接触由平行黏结与 Burger 随机组成，把模型占比、选择规则和种子作为
待标定输入。至少执行接触占比、三个独立种子和空间聚集度敏感性，并检查接触
比例变化是否同时改变抗拉能力、配位、蠕变和破坏位置。

## 3. 温度换算：TTSP + WLF

材料满足热流变简单性且试验数据支持时，可用**时温等效原理（TTSP）**构建主曲线，并用 WLF 方程拟合参考温度 `T_ref` 与目标温度之间的时间/频率移位因子：

```
log10(a_T) = -C1*(T - T_ref) / (C2 + T - T_ref)
```

- a_T：移位因子
- C1、C2：与材料和参考温度定义相关的拟合常数。`C1≈8.86、C2≈101.6 K` 只是常见的理想化参考组合（常与 `T_ref≈Tg+50 K` 配套），不是可无条件用于沥青或混合料的“通用值”。

`a_T` 用于移动响应曲线的时间/频率轴。只有在移位约定、热流变简单性和拟合模型均已声明时，才能据此变换 Burger 的特征时间或黏壶参数；不得把 `a_T` 不加区分地乘到全部 `k_m、c_m、k_k、c_k`。

每套 Burger 参数必须带温度、频率/加载时间和离散化标签。对于 60℃ 数据，若反演得到较小 `c_m`，应解释为较低黏性/流动阻力和较快永久流动；不能把它称为“高黏性”，也不能用无数据支撑的温度表生成参数。

## 4. 计算加速的时间压缩审计

时间压缩与温度移位分开记录。对线性 Burger 恒载蠕变，若定义：

```text
t' = t / lambda
k_m' = k_m
k_k' = k_k
c_m' = c_m / lambda
c_k' = c_k / lambda
```

则 `t'/c_m' = t/c_m` 且 `k_k t'/c_k' = k_k t/c_k`。实现前后必须用数值
探针直接比较，避免把 `lambda` 的乘除方向写反。

最低审计内容：

- `lambda=1` 与每个候选 `lambda` 的完整加载—保持—卸载—回复曲线；
- 峰值、保持末应变、残余应变、Kelvin 特征时间和稳态流动斜率误差；
- 时间步、可用的动能/应变能/摩擦耗能、断键/滑移数和接触数变化；PFC5
  Burger 本身不提供能量分区，不能把缺失量补成零或伪造黏壶耗能；
- 若用于车辙，另与移动轮小模型比较足迹、反力、轮迹和横向隆起。

任何论文中的 `lambda` 仅能登记为该论文案例值。没有上述对照时不得给出
`time_equivalence_validated: true`，也不得把等效静载称为真实动荷载。

## 5. 混合料级验证

```
Step A  固体骨架/非 Burger 接触：以宏观 E、ν 和独立界面试验为目标，在固定颗粒尺度与结构下反演；不得把单接触闭式近似当作通用宏—微观换算
Step B1 结合料先验：JTG T 0627/T 0628/T 0647/T 0648 数据只约束温度、频率、恢复、非线性或损伤趋势，不直接拟合砂浆接触参数
Step B2 砂浆尺度标定：仅用同一砂浆材料的实测宏观曲线作为 RVE 目标；若无砂浆试验，则把该层级列为不可识别并采用有界假设
Step B3 接触参数反演：固定离散化、单位和接触对，通过砂浆 RVE 响应拟合 Burger (k_m,c_m,k_k,c_k)，不得直接重命名宏观参数
Step C  混合料宏观验证：单轴蠕变(60℃)/动态模量/间接拉伸等独立混合料数据 → DEM 复现；不能用同一曲线同时标定和确认
Step D  车辙验证：使用独立温度/荷载/级配或留出的室内车辙数据，对比完整曲线、DS/车辙深度和变形模式
          是否接受由预先声明且有试验精度、标准或项目依据的容差决定；不得使用无来源的统一 10% 判据
```

## 6. 标定产物

- 一套带温度标签的 Burger 参数表（如 `burger_params_60C.yaml`）。
- 拟合来源、材料层级（binder/mastic/mixture）、方法与拟合优度；结合料 DSR/BBR/MSCR/LAS 只能标为先验或约束，除非同一砂浆材料确已按声明协议测试。
- 温度换算方法（TTSP/WLF 及其常数）。
- 与室内试验的偏差记录（DS 对比等）。
- 每条曲线的材料层级、方法编号、温度/频率/应力历史和 source ID。
- 混合接触的模型数量/占比、选择规则、随机种子、空间分布和拉伸承载模型。
- 时间压缩的 `t -> t'` 约定、dashpot 变换、未加速对照和未保持的物理量。
