# Burger 黏弹性模型原理

## 1. 为什么沥青砂浆需要 Burger 模型

沥青是典型的黏弹性材料：其力学响应同时依赖**时间**（加载速率/频率）与**温度**。线性弹性模型（linear）或弹脆性模型（linearpbond）无法描述：

- 蠕变（恒定荷载下变形随时间增长）
- 应力松弛（恒定变形下应力随时间衰减）
- 永久变形（卸载后不可恢复的黏性流动，可表示车辙来源之一）

Burger 模型由 Maxwell 与 Kelvin 两个子模型串联，可同时刻画**瞬时弹性、黏性流动、延迟弹性**三类响应，是 DEM 中表示沥青砂浆时间相关行为的一种简化接触本构。

## 2. 四元件力学构成

```text
                       ┌──── k_k ────┐
──── k_m ──── c_m ─────┤              ├────
                       └──── c_k ────┘
   Maxwell：k_m 与 c_m 串联      Kelvin：k_k 与 c_k 并联
```

| 元件 | 组成 | 物理含义 | 对应变形 |
| --- | --- | --- | --- |
| Maxwell | 弹簧 k_m 串联阻尼 c_m | 瞬时弹性 + 黏性流动 | 瞬时变形 + 永久变形（不可恢复） |
| Kelvin | 弹簧 k_k 并联阻尼 c_k | 延迟弹性 | 蠕变 + 回复（随时间可恢复） |

### 参数角色

- **Maxwell 黏壶系数 c_m**：控制稳态黏性流动；在其余条件不变时，c_m 越大表示黏性/流动阻力越大，永久流动越慢，c_m 越小则流动越快。它是影响高温永久变形的重要参数之一，但不是车辙的唯一控制量。
- **Maxwell 刚度 k_m**：瞬时弹性响应。
- **Kelvin 刚度 k_k / 黏壶系数 c_k**：控制延迟弹性；固定 k_k 时，迟滞时间为 `tau_k = c_k/k_k`，c_k 越大，延迟变形与回复越慢。

在一维恒定力 `F_0` 下，理想 Burger 模型的蠕变位移为：

```text
u(t) = F_0/k_m + F_0*t/c_m + F_0/k_k * (1 - exp(-k_k*t/c_k))
```

因此稳态流动速率为 `F_0/c_m`。这直接说明 `c_m 小` 对应较低黏性/流动阻力和较快流动，而不是“高黏性”。

## 3. 法向与切向参数

PFC5.0 中 Burger 模型法向（normal）与切向（shear）各有一套 Maxwell+Kelvin，共 8 个刚度/黏壶参数：

| 法向 | 切向 | 含义 |
| --- | --- | --- |
| bur_knm | bur_ksm | Maxwell 刚度（normal/shear） |
| bur_cnm | bur_csm | Maxwell 黏壶系数 |
| bur_knk | bur_ksk | Kelvin 刚度 |
| bur_cnk | bur_csk | Kelvin 黏壶系数 |

另有摩擦系数 `bur_fric` 描述剪切滑移极限。

## 4. 蠕变与回复行为

- 施加恒定荷载：瞬时弹性变形（k_m）→ 延迟蠕变（Kelvin，指数趋近）→ 稳态流动（c_m 线性增长）。
- 卸载：瞬时弹性回复（k_m）→ 延迟回复（Kelvin）→ 残留永久变形（Maxwell 黏性流动不可恢复）。

Maxwell 黏壶产生的卸载后残留变形可表示车辙累计中的黏性流动部分；实际混合料车辙还可能包含颗粒重排、界面滑移、压密与损伤，不能仅由 `c_m` 或 Burger 接触解释。

## 5. 温度敏感性

沥青黏弹性对温度敏感，但不能仅凭温度表直接指定某个接触参数。对同一离散化和加载条件，升温通常会降低表观刚度并加快蠕变；各 `k`、`c` 的变化仍须由材料数据反演。若 60℃ 拟合结果为较小 `c_m`，其物理含义是较低黏性/流动阻力和较快永久流动，不能写成“高黏性”。具体试验温度必须按所用标准与项目条件确认。

温度换算可在材料满足热流变简单性且数据支持时采用时温等效原理（TTSP）与 WLF/Arrhenius 移位；移位主曲线不等于把某个 WLF 因子直接套到全部接触参数，见 `calibration.md`。
