# JTG 3410-2025 T 0719 车辙试验与 PFC3D 映射

本文件按 JTG 3410-2025 T 0719-2025（印刷页 441-445）建立模型契约，不替代
规范原文，也不分发完整仪器参数、允许误差或验收限值表。JTG E20-2011 数值不得
作为当前模型默认值。

## 1. 当前方法定位

T 0719-2025 以往返橡胶轮测定沥青混合料试件动稳定度，评价高温性能。当前
方法链至少包括：

- 室内轮碾成型试件追溯 T 0703；现场切割试件追溯 T 0701 和取样记录；
- 记录试件密度、空隙率、制作方法和方向；
- 锁定试验温度、标准荷载、轮胎/轮迹、计数和调温条件；
- 输出原始变形-行走次数曲线，再计算动稳定度和车辙深度。

固定循环压头、加速时间映射或缩尺试件是 DEM 替代路线，不是 T 0719 的规范
车轮运动；必须通过移动轮 strip pilot 建立等效关系。

## 2. 试件与计数契约

- 当前方法允许标准宽度室内成型试件和较窄的现场切割试件；宽度会进入动稳定度
  系数。尺寸、厚度和来源逐项记录，不再把某个历史尺寸硬编码为唯一试件。
- “行走次数”、单程、往返、实验分钟和 PFC solver cycle 是五个不同量。当前
  方法的设备计数与实际单程/往返关系必须按锁定装置核对并写入 CSV 元数据。
- 提前达到终止变形时，终点计数和向前回溯的评价区间按当前方法处理；不能继续
  套用旧版 `45 min/60 min` 简写。

建议原始输出：

```text
physical_time, solver_cycle, one_way_pass, round_trip,
wheel_x, wheel_z, commanded_load, measured_reaction,
reaction_error, deformation_p1, deformation_p2, deformation_p3,
deformation_p4, deformation_p5, deformation_p6, deformation_p7,
mean_deformation, specimen_temperature
```

## 3. 变形测量映射

实验在一次往返过程中于轮迹中部及两侧多个固定位置采集变形，并以水平平均值
作为该次变形。PFC3D 至少实现以下两级结果：

1. 与实验固定位置相对应的七点或经批准的等效测点；
2. 轮迹带的连续场统计（最深点、稳健分位数、横向隆起）。

七点平均是规范对标量，连续场统计是模型诊断量，两者不得混为同一“车辙深度”。
测点随轮运动还是固定于试件、采样在前进还是返回行程、自由表面基准如何更新，
都必须锁定。

## 4. 当前指标实现

按当前方法，将两个评价行走次数记为 `t1`、`t2`，对应平均变形为 `d1`、`d2`，
试件宽度系数为 `C1`：

```text
DS = C1 * (t2 - t1) / (d2 - d1)
```

实现时必须：

- 从当前方法读取正常终止和提前终止时的 `t1/t2` 选择规则；
- 对 `d2 <= d1`、传感器分辨率、舍入、异常点和提前终止给出显式状态；
- 保留宽度系数来源，不使用没有当前依据的额外机器/试件系数；
- 将当前方法的车辙深度参考次数与动稳定度区间分开计算；
- 分别交付原始测点、平均变形、DS 和车辙深度。

## 5. PFC3D 实现门槛

1. **空载运动**：轮中心线、行程、反转、平移/滚动符号和 facet 分辨率通过。
2. **接触与载荷**：压强只用于定义物理目标；PFC 通过运动/伺服得到反力，并
   记录整个行程的反力误差和离散接触足迹。
3. **温度**：试件和轮的温度输入分开记录；Burger 参数来自同温度下标定。
4. **测量**：预载参考面、固定测点、连续轮迹带和横向隆起都可重建。
5. **层级**：RVE 验证材料，strip pilot 验证运动/反力/测量，全尺寸模型只在
   前两级通过后运行。
6. **重复性**：实验试件组与 DEM seeds 分开；模型重复不能代替实验异常值规则。
