# 旧版 JTG E20-2011 T0709 马歇尔核对清单

> JTG E20-2011 已于 2025-10-01 被 JTG 3410-2025 替代。本文件仅用于复现
> 旧项目，且未收录条款原文。新项目必须先核对 2025 版的方法编号和条款。
> 本文件不提供记忆性数值。

## 1. 需从 T0709 原文核对的量

- [ ] 标准马歇尔试件尺寸（直径 × 高度）
- [ ] 加载速率（压头下降速率）
- [ ] 试验温度与试件保温条件
- [ ] 稳定度 MS 的定义与读数单位（kN）
- [ ] 流值 FL 的定义与读数单位（0.1 mm）
- [ ] 马歇尔模数 T = MS / FL
- [ ] 试件高度非标准时的修正系数

## 2. 旧版流值修正来源门槛

DEM 直接输出的“峰值时压头位移”不是规范流值。复现旧项目时必须从该项目
实际采用的 JTG E20-2011 合法副本核对：

- [ ] 切线起点的确定方法（原点 / 预压修正点）
- [ ] 流值读数单位（0.1 mm）
- [ ] 修正的具体几何步骤

## 3. 与配合比设计的关系

马歇尔稳定度/流值用于**最佳油石比**确定（配合比设计），与体积指标（空隙率、VMA、VFA）配合使用。建模时马歇尔试验提供两个对标量：稳定度 MS、流值 FL。
