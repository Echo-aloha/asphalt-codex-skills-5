# 沥青混合料 PFC5 建模总览

> 本文件为 `pfc-asphalt-mixture` 的核心参考。内容提炼自旧版试验/设计
> 框架。`../scripts/minimal_specimen_smoke.p3dat` 是独立编写的 PFC3D 5.0
> 最小运行探针；它验证命令流与完整六面边界，不代表实际级配、压实或材料标定。
> 以接触模型等效砂浆时，砂浆并非具有独立质量和体积的显式颗粒相。

## 1. 三相材料表征

沥青混合料是「集料 + 沥青砂浆 + 空隙」三相复合材料：

下表中的物理粒级边界应由项目级配/规范确定，DEM 可分辨边界则由试件尺度、
最小颗粒与计算预算确定；两者不能自动等同。`2.36 mm` 和 `3–5%` 仅属于后文
旧版密级配示例，不是所有混合料或所有 DEM 模型的固定要求。

| 相 | 粒径范围 | PFC 表示 | 备注 |
| --- | --- | --- | --- |
| 项目定义的粗集料 | 按所选级配/规范 | clump、ball 或经验证的形状对象 | 表示方法由形状/嵌挤目标与分辨率决定 |
| 项目定义的细集料 | 按所选级配，且可能跨越 DEM cutoff | ball/clump 或并入均质相 | 显式与均质化部分必须分别声明 |
| 矿粉 | 按所选级配/规范 | 可并入沥青砂浆或在可解析时显式表示 | 不强制单一路线 |
| 沥青砂浆 | 沥青+细料+矿粉均质化 | Burger 黏弹性接触模型 | 非独立颗粒 |
| 空隙 | — | 颗粒间残余孔隙 | 目标来自项目/试验/适用规范并做闭合验证 |

### 两条建模路线

- **Route A 均匀砂浆**：显式解析所选集料对象，砂浆由经标定的接触定律等效。计算量可控，但等效砂浆没有自动独立的质量/体积。
- **Route B 解析细料**：在可分辨范围内加入细料对象并定义界面；未显式建模的沥青/矿粉仍需声明为均质化部分。该路线分辨率更高但不自动更准确，需做尺度与成本验证。

## 2. 接触模型分配策略

| 接触对 | 模型 | 关键属性示例 | 说明 |
| --- | --- | --- | --- |
| 集料-集料 | linear（无黏结） | `kn`、`ks`、`fric` 均由标定给出 | 摩擦嵌挤，不内置通用数值 |
| 集料-集料（可选） | Hertz | 按 PFC5 Hertz 属性与固定离散化标定 | 非线性弹性接触 |
| 集料-砂浆 | burger | 见 burger skill | 黏弹性 |
| 砂浆-砂浆 | burger | 见 burger skill | 黏弹性 |
| 集料-墙 | linear 或经论证的界面模型 | 按模具/压头/轮及润滑条件标定 | 不把“高摩擦”写成通用默认 |

`fric` 是接触滑动摩擦系数，不等于可直接互换的宏观内摩擦角。集料嵌挤还受
形状、配位、级配、围压和边界影响；是否加入黏结由相抽象和标定目标决定。

## 3. 分阶段建模流程（可恢复）

每个阶段一个存档，便于逐阶段调试：

| 阶段 | 存档 | 内容 | 关键命令 |
| --- | --- | --- | --- |
| 1 试模 | `00_setup` | domain + 6 面刚性墙 | `wall create` / `wall addfacet` |
| 2 颗粒 | `01_particles` | 按级配生成集料 | `ball create` / `clump create` |
| 3 沉降 | `02_settled` | 重力沉降（临时线性接触） | `cmat default ... linear` + `set gravity` |
| 4 压实 | `03_compacted` | 顶墙下压至目标空隙率 | `wall attribute zvelocity` |
| 5 接触 | `04_burger` | 在保留装配状态的前提下安装 Burger + 线性墙 | 保存切换前状态；设置未来接触默认；按已验证的 PFC5 路径重赋既有接触；重新平衡并审计 |

### 3.1 试模墙（完整六面边界）

不要把带省略号的墙体片段当作模板。先运行
`../scripts/minimal_specimen_smoke.p3dat`，它在 PFC3D 5.0 中使用
`wall generate box` 生成完整六面试模，并生成一个可检查的最小颗粒装配。
生产模型再根据几何、墙 ID、法向和加载方式替换边界，并逐面核对接触。

该资产只证明 PFC5 命令流可执行；它不声称构成车辙板、马歇尔试件或规范试件。
不得仅凭 smoke test 把 `runtime_validated` 提升为生产验证。

### 3.2 接触切换事务

`contact delete` 会清除既有接触及其历史，因此不得作为临时线性接触切换到
Burger 的通用默认步骤。统一流程是：

1. 保存并记录切换前状态、接触数、未平衡力和关键反力；
2. 为未来新接触设置目标 `cmat` 默认和接触对规则；
3. 仅使用已在目标 PFC5 环境通过探针的命令重赋既有接触模型/属性；
4. 重新平衡，比较切换前后的颗粒、接触、孔隙率、合力和能量；
5. 若目标模型不能可靠原位重赋，则从切换前存档采用经验证的重建路径，明确记录
   历史重置，而不是静默删除接触。

### 3.3 颗粒生成：先选命令语义

PFC5 官方帮助明确区分：

- `ball distribute` / `clump distribute` 为达到目标孔隙率而放置对象，**允许
  显著重叠**；孔隙率目标不扣除重叠，而且一次新的 `ball distribute` 不会把
  已有球纳入该次目标计算。它适合“生成后消重叠/压实”的路线，但初始目标不是
  最终空隙率。
- `ball generate` / `clump generate` 只放置不重叠对象，达到目标数量或尝试
  次数上限即停止；因此必须核对实际生成数，不能假定要求数量已经达到。
- `ball create` / `clump create` 创建单个对象；对 clump，体积、惯量和质心必须
  显式给定或通过 `calculate`/模板的 `pebcalculate`、`surfcalculate` 求得。

上述对象都要求先定义 domain；循环中只能在 timestep 计算点 `0.0` 之前创建。
固定 `set random <seed>`，并记录命令、分档、实际对象数、初始重叠统计和松弛后
级配/体积误差。

### 3.4 压实与空隙率

采用与试验制备相符的边界运动/伺服压实，直到达到项目目标空隙率及其他
预先声明的压实判据。`3–5%` 可作为特定密级配 AC 旧版示例，不能自动用于验收。
压实后输出最终空隙率和质量-体积闭合供验证：

```fish
solid_vol = Σ ball_volume + Σ clump_volume
final_poro = 1 - solid_vol / (L * W * H_top)
```

其中 clump 必须使用其已计算/声明的 clump 体积，不能把相互重叠的 pebbles
球体积直接求和。若砂浆只存在于接触本构中，它没有自动贡献显式对象体积；物理
空隙率还需通过结合料/砂浆的质量—体积台账闭合，不能只用 DEM 对象孔隙率代替。

## 4. 设计空隙率与油石比

- 油石比、沥青含量定义及对应体积必须由项目数据和实测密度换算；约 5%/84% 仅是示例量级。
- 目标空隙率采用项目配合比、试验结果和适用规范；3–5%（密级配 AC）与 3–4%（某些 SMA）只作示例，不能跨材料套用。
- 压实阶段的目标高度 = solid_vol / (L×W×(1−空隙率))。

## 5. 可复现性要求

- 固定 `set random <seed>`，记录种子值。
- 级配、油石比、空隙率、接触参数全部显式写出，不依赖 GUI 元数据。
- 存档按阶段号命名，不删除 `.p3sav`（生成态不入库，仅脚本与参数入库）。
