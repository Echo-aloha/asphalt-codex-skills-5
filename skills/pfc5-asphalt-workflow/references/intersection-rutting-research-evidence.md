## 可吸收的研究设计

### 接触体系

- 论文将模型划分为集料—集料、砂浆—砂浆和砂浆—集料三类接触。
- 集料—集料使用线性接触；砂浆相关接触用平行黏结与 Burger 接触共同表示，
  目的是在 Burger 不承受拉力的限制下同时保留黏结与时间相关响应。
- 论文用砂浆蠕变曲线拟合宏观 Burger 四参数，再通过弹性梁近似给出细—宏观
  换算初值，并按温度改变接触参数或接触比例。

这些内容适合作为**候选接触架构与初值生成假设**，不能证明随机替换比例、
闭式换算或表中数值可跨粒径、配位、级配、温度和 PFC 版本移植。生产模型必须
输出各接触对的总数、模型数、占比、随机种子、空间分布和切换前后状态，并用
固定离散化后的 RVE/试件反演确认。

### 等效静载与时间压缩

论文把移动/正弦轮载简化为固定矩形加载区，再用时间压缩降低计算量。对线性
Burger 蠕变式，在保持刚度不变且令 `t' = t / lambda` 时，为保持无量纲时间项
和稳态流动项不变，应满足：

```text
c_m' = c_m / lambda
c_k' = c_k / lambda
t' / c_m' = t / c_m
k_k t' / c_k' = k_k t / c_k
```

论文案例采用 `lambda = 10000`，并把等效作用时间从 782 s 缩短到 0.0782 s；
该数值是研究案例选择，不是本包默认值。论文相应位置的依据引用存在空缺，且
这种变换只保持所用线性 Burger 恒载蠕变表达式中的特定不变量，不能自动保持
移动足迹、卸载/回复、停驻、循环路径、频率谱、惯性、接触重排、黏结破坏或
摩擦耗能。

因此每次加速都必须提供未加速小模型对照，分别比较完整蠕变/回复曲线、永久
变形、反力、接触状态、能量和时间步敏感性。没有这些证据时，只能标记为
`accelerated_surrogate`，不能称为规范车辙试验或真实动荷载重现。

### 交叉路口竖—水平耦合

- 论文以 `F_h = mu F_v` 表示制动/启动引起的水平作用，并研究不同温度、厚度
  和水平作用等级。
- 关键诊断包括水平力正/反向面的非对称竖向变形、砂浆/集料位移场、横向隆起、
  颗粒滑移及沿深度的剪应力分布。
- 论文用 PFC3D measure 区域组成三维测量矩阵，汇总不同深度的剪应力。

`mu` 在此是外部荷载需求的参数化，不等同于 DEM 接触摩擦系数。模型必须分开
记录轮—试件界面摩擦、材料接触摩擦和目标水平/竖向反力比，并验证实际反力
向量、滑移和做功。测量结果必须声明应力张量分量、坐标轴、符号、区域半径、
空间重叠、体积加权、采样时刻和空测区处理，不能只输出一个未定义的“剪应力”。

论文还明确指出其水平力正向面未设置侧向边界，允许颗粒自由移动；这会改变
应力重分布。因此自由侧面、受限侧面和代表性周期/远场边界至少需要一组边界
敏感性对照，论文的非对称变形不能直接外推到现场。

## 建议验证矩阵

| 层级 | 最少对照 | 通过证据 |
| --- | --- | --- |
| 接触探针 | Burger 与黏结接触分别加载/卸载 | 参数角色、受拉边界、回复和时间步正确 |
| 砂浆 RVE | 实测蠕变加载+回复；至少两个温度/时长 | 参数可识别性、拟合与留出确认 |
| 混合接触 RVE | 接触占比、种子和空间分布敏感性 | 宏观响应不由一次随机替换偶然决定 |
| 竖向 strip | 移动轮与固定等效压头小模型 | 反力、足迹、车辙曲线和变形模式的等效误差 |
| 时间压缩 | `lambda=1` 与候选 `lambda` | 曲线、残余变形、状态变量和能量误差随 `lambda` 可接受 |
| 耦合 strip | 竖向基线与正/反向水平荷载 | 反力向量、非对称变形、隆起和滑移可重建 |
| 边界/尺度 | 自由、受限及至少两种厚度/分辨率 | 剪切带、深度剖面和车辙结论稳健 |
| 实验确认 | 独立车辙曲线或现场/路槽数据 | 预先声明的误差度量和接受阈值通过 |

论文报告其三个 60 ℃案例的最终变形平均误差小于 13%，但同一研究也指出孔隙率、
固定静载和边界简化会带来偏差。这个结果只能记录为该论文案例的确认结果，不能
成为统一验收阈值。

## 预估模型边界

论文的交叉路口预估框架使用荷载次数、频率、压力、厚度、水平作用参数、剪应力
和动态模量—相位角组合量等变量。Skill 可借此建立候选特征清单，但必须避免
双重计数（例如 `mu` 与由同一荷载计算的 `tau`）、量纲不一致和把同一批数据同时
用于回归与验证。交付时保存原始试验、DEM 修正和独立验证三个数据分区，并报告
外推范围、参数相关性和不确定性；不在 Skill 中固化论文回归系数。
